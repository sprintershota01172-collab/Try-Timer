# トライタイマー

日付とトライ名だけで登録できる、スマホ向けのサイクルタイム計測アプリです。

## 使い方

1. `index.html` を対応ブラウザで開きます。外部ライブラリやサーバーは不要です。
2. 「新しいトライ」でトライ名と日付を入力します。
3. 最初のタップで開始し、以降はタップごとにショットを記録します。
4. 計測ボタン直下の「すぐメモ」に入力すると、今回のショットにメモを残せます。「直前」に切り替えると最後の確定済みショットも編集できます。
5. 「設備停止」「トラブル」などのボタンを押すと、計測は止めずに発生時刻を記録します。「項目設定」からボタン名を追加・編集・削除できます。
6. 「停止」で一時停止します。再開すると未確定のショットを続けて計測します。
7. 「履歴」で検索・編集・比較、「データ」でCSV出力とJSONバックアップを行います。

## 機能

- 大きな計測ボタン、0.01秒表示、直前ラップの取り消し
- 計測ボタン直下の常設メモ欄（今回／直前ショット切替）と、ショットごとのメモ・集計除外
- トラブル・設備停止などをワンタッチ記録（発生時刻、計測経過時間、ショット番号を保存）
- ワンタッチ項目は任意に追加・編集・削除可能。イベント記録は履歴、CSV・JSONバックアップに含まれます
- 平均・最大・最小・有効数・母標準偏差・範囲の自動集計
- トライ名と日付で検索、同じトライ名の履歴比較
- ライト／ダークモード
- localStorageへの自動保存とオフライン動作
- CSV書き出し、JSON書き出し／読み込み

## 保存と計測

入力した記録はブラウザ内に保存され、GitHubや外部サーバーへ送信しません。
JSONの読み込みは現在のデータを置き換えます。ブラウザの保存データを削除する前にバックアップしてください。

旧形式のバックアップは計測記録と日付を引き継ぎ、名前を「トライ 1」などに付け直します。
登録情報はトライ名と日付だけを保持します。

通常の計測には `performance.now()` を使用します。再読み込みや端末休止を端末時計で補完したショットは、要確認として集計から除外します。
スリープ防止は対応ブラウザと安全な接続環境が必要で、端末の省電力設定などで利用できない場合があります。

本リポジトリへの保存だけではWeb公開は有効になりません。ファイルをダウンロードして使用できます。

## 画面固定とトライ名

計測画面はスクロールしない固定操作画面になりました。タイマー、停止、ワンタッチ記録、メモを順に表示し、集計・イベント履歴・ショット履歴は「記録・集計」で開きます。iPhoneのキーボード表示中は上部ヘッダーなどを隠し、計測操作の領域を優先します。画面幅の拡大縮小を抑制し、メモのフォントサイズは16px以上です。

新規トライは「プレトライ」「工程検証トライ」「工程確認会」「量産トライ」「ハイボリュームトライ」と回数（#1〜#99）から選びます。表示例：`工程検証トライ (#2)`。過去の自由入力名は変更するまでそのまま保持します。

## 計測中の操作と終了保存（2026-10-17）

- ストップウォッチは計測画面でコンパクト表示します。ラップを押すと直前のショットの秒数と、その前のショットの秒数を計測画面内に表示します。
- 計測画面のメモ欄はワンタッチ記録の下に配置します。iPhoneのキーボード表示中も画面の大幅なリサイズや要素の並べ替えを行わないようにしました（ブラウザ側のキーボード挙動による制約はあります）。
- ワンタッチ記録はストップウォッチ操作ボタンの直下に配置し、**4列×3行の12枠**を常時表示します。登録数が12件未満のときは空き枠と「＋項目」を表示します。13件目以降はボタン欄だけをスクロールできます（最大24項目）。メモ欄はその下です。
- 「保存して終了」を押すと確認画面を表示し、確認後にタイマーを止めてトライの終了時刻を端末内に記録します。履歴に「保存済み」と表示します。終了したトライへの追加ラップはできません。新しいトライから次の計測を開始してください。
- ショットとイベントは従来どおり計測中も自動保存します。「保存して終了」は計測を確定するボタンです。別端末への保存・移動はデータ画面のJSONバックアップを使います。
